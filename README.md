# heat_inference_code
Code for the manuscript "Hunting for Maxwell's Demon in the Wild", [arxiv:](https://arxiv.org/abs/2504.11329)


### Info_Engine_Sim_Data_and_Figure

Contains code for simulating the colloidal information engine, analyzing data, and plotting Figure 2 in the manuscript.

### Kinesin_Simulation_Code

Contains code for simulating a kinesin motor pulling a diffusive cargo with nonequilibrium noise, analyzing data, and plotting Figure 3 in the manuscript.
